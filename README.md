# Debate Quiz API

A FastAPI backend that uses OpenAI to generate debate arguments, quiz questions, hints, and answer evaluations.

## How It Works

1. **Generate arguments** — You send a topic and difficulty. The API returns main arguments, counter arguments, and rebuttals.

2. **Generate quiz** — You send a topic, difficulty, and an argument. The API returns a multiple-choice question with 4 options, the correct answer index, and an explanation.

3. **Get a hint** — You send a question and its context arguments. The API returns a helpful hint without revealing the answer.

4. **Evaluate answer** — You send a question, the student's answer, the correct answer, and difficulty. The API returns short, constructive feedback as a debate coach.

All responses are generated by OpenAI (GPT-4o-mini) and returned as JSON.

## Setup

1. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Create a `.env` file and add your OpenAI API key:

   ```
   OPENAI_API_KEY=your_key_here
   ```

## Run

```bash
uvicorn app.main:app --reload
```

The API will be available at `http://localhost:8000`. Open `http://localhost:8000/docs` for interactive Swagger docs.
